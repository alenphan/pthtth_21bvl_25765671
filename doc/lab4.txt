package network;
import java.net.InetAddress;
import java.net.UnknownHostException;
public class HostInspector {
public static void main(String[] args) {
if (args.length != 1) {
System.out.println("Usage: java network.HostInspector <hostname>");
return;
}
try {
InetAddress[] addresses = InetAddress.getAllByName(args[0]);
System.out.println("Host: " + args[0]);
for (InetAddress address : addresses) {
System.out.println("- IP: " + address.getHostAddress());
System.out.println(" Canonical: "
+ address.getCanonicalHostName());
System.out.println(" Loopback: "
+ address.isLoopbackAddress());
System.out.println(" Site local: "
+ address.isSiteLocalAddress());
}
} catch (UnknownHostException e) {
System.err.println("Không phân giải được host: " + args[0]);
}
}
}

• Cài đặt cùng tập lệnh trên UDP; UDP không cần lệnh QUIT cho phiên kết nối.
• Dùng DateTimeFormatter với khuôn dạng dd MM yyyy và HH mm ss.
• Viết đoạn so sánh hành vi khi server dừng giữa lúc client đang hoạt động.

Bài 5 Chat TCP nhiều client
• Mỗi client chọn nickname duy nhất sau khi kết nối.
• Tin nhắn của một client được broadcast cho các client còn lại.
• Server dùng thread pool và cấu trúc thread safe để quản lý danh sách người gửi.
• Hỗ trợ các lệnh USERS, MSG nội_dung và QUIT.
• Khi một client ngắt bất thường, server loại client đó và tiếp tục hoạt động.
Bài 6 Thực nghiệm so sánh TCP và UDP
• Gửi 1000 thông điệp kích thước cố định bằng TCP và UDP trên localhost.
• Đo tổng thời gian và số phản hồi nhận được; lặp lại ít nhất năm lần.
• Không kết luận UDP luôn nhanh hơn chỉ từ một lần chạy.
• Ghi rõ môi trường, kích thước thông điệp, timeout và phương pháp đo.
Bài 7 Server lưu nhật ký tin nhắn
• Client gửi HELLO clientId trước khi gửi nội dung.
• Server lưu tin nhắn theo từng client vào data logs clientId.txt.
• Mỗi dòng gồm timestamp, địa chỉ remote và nội dung.

Bài 8 Truyền file TCP an toàn
• Client gửi tên file, kích thước kiểu long và mã SHA 256 trước phần dữ liệu.
• Server lưu file vào thư mục upload cố định và không chấp nhận đường dẫn do client chỉ định.
• Server đọc đúng số byte đã khai báo, không dùng EOF làm ranh giới duy nhất.
• Sau khi lưu, server tính lại SHA 256 và trả OK hoặc ERR HASH_MISMATCH.
• Kiểm thử file rỗng, file văn bản tiếng Việt, file ảnh và tên chứa chuỗi ../.
Bài 9 Multicast thông báo
• Sender gửi thông báo tới địa chỉ multicast 239.255.0.1 thuộc phạm vi quản trị cục bộ.
• Ít nhất hai receiver cùng tham gia group và nhận thông điệp.
• Chỉ rõ NetworkInterface khi joinGroup và rời group trước khi đóng socket.
• Ghi nhận trường hợp multicast bị chặn bởi Wi Fi, VPN hoặc firewall; luôn có phương án kiểm thử localhost
hoặc mạng phòng lab.
Bài 10 UDP discovery kết hợp TCP service
• Client broadcast hoặc multicast DISCOVER_SERVICE qua UDP.
• Server trả SERVICE tên_dịch_vụ tcp_port phiên_bản.
• Client dùng địa chỉ nguồn của datagram phản hồi để kết nối tới TCP server.
• Thiết kế timeout, loại bỏ phản hồi trùng và hiển thị nhiều server nếu có.
